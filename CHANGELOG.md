# Changelog

All notable changes are listed here. Versions follow [Semantic Versioning](https://semver.org).

## [0.1.0] - 2026-11-02

First release.

- Gestures: edge slides on all four edges, corner holds in all four corners, 3/4-finger swipes and taps, 4-finger
  twist, 5-finger pinch and twist, optional 3-finger drag.
- Actions: presets, custom keyboard shortcuts, launch app/file, open URL, and continuous volume, brightness, seek,
  horizontal scroll, zoom, tabs, desktops or custom shortcut pairs.
- GPUI settings window following the Windows theme, with live gesture feedback and a Test button.
- Warnings when Windows' own 3/4-finger gestures would also run.
- Tray icon with pause, start with Windows and quit; per-user NSIS installer and MSI.
